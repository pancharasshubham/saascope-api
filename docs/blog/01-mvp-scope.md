# MVP Scope Decisions

## Features Included

* Authentication
* CSV Upload
* Insight Generation
* Report Persistence
* Search
* Filtering
* Pagination
* Retry Workflow
* Event History
* Dashboard Analytics

## Features Explicitly Deferred

* SaaS Integrations
* Stripe Integration
* Background Jobs
* Email Notifications
* Duplicate Upload Detection
* Team Collaboration
* Billing

## Reasoning

The objective was validation, not scale.

Every feature was evaluated against one question:

"Does this help prove that SaaScope solves a real problem?"
